# 分站内容规律与关键词方案

研究日期：2026-09-23。当前 SQLite 共 274 条样本：电子信息学院 109、本科生院 82、国际交流部 11、科发院 9、第二课堂 24、学生资助中心 15、武大官网 4、校团委/未来网 20；综合事务服务中心和信息公开网当前窗口内没有入库样本，因此这两站同时参考了公开列表页的历史标题。分站词库见 `config/site_keyword_profiles.json`。

## 结论

同一个词在不同网站的含义并不相同。“申报”出现在本科生院学生通知里通常是学生机会，出现在科发院则大多是教师或课题负责人申报科研项目；“名单”在本科生院可能关系到学生录取或创新学分，需要复核，在团委制度文件中往往只是已经完成的获奖结果；第二课堂标题即使没有“报名”，其公开活动记录仍然带有报名起止时间，站点和接口状态本身就是强机会信号。

因此下一版规则应分成三层：

1. 全站通用层：只处理报名、申请、招募、截止时间、事后报道、受众等稳定语义。
2. 网站/栏目先验层：处理“第二课堂当前活动默认有价值”“科发院项目申报默认不是本科生机会”等站点差异。
3. 结果态层：名单、公示、表彰不直接判为无关；根据网站和事项进入待复核或过滤。

## 各站规律

### 电子信息学院

- 学工通知、本科生教育、学术讲座、留学通知是高价值栏目。
- 学生活动栏目在历史样本中主要是见面会、迎新和活动完成后的新闻回顾。
- 正向词：本科生、奖学金、综测、推免、竞赛、讲座、学生助理、报到注册、导师双选、交流项目。
- 待复核词：拟推荐、拟聘用、名单公示、推优入党、增补工作人员。
- 降权词：圆满举行、见面会、迎新、获批、内设机构。

### 本科生院

- 学生通知 55 条中绝大部分对本科生有直接价值；综合业务 27 条中，教师项目和教务内部管理事项占比较高。
- 标题不一定包含传统机会词。学业预警、教学安排调整、水平测试、照片采集、证书补办、公共教室开放、封楼、试音和中期退课都应保留。
- 综合业务中的教师、值班、课表编排、课程建设和项目验收应降权；但“教学安排调整”“封楼”“学生评教”和“大学生创业扶持”需要保留。
- 录取名单、推免拟推荐名单、创新学分结果和结题结果进入待复核，不直接过滤。

### 武汉大学官网通知公告

- 是全校兜底入口，主题混合度最高。
- 学生机会、珞珈讲坛、放假和公共资源开放有价值；停水、停电、道路封闭等校园运行信息也会直接影响学生。
- 采购、招标、干部任免、会议纪要等行政事项降权。

### 学生资助管理中心

- 通知公告和勤助信息几乎都面向学生，当前 15 条样本全部被 `rules_v1` 保留。
- 奖助学金、贷款、困难认定、勤工助学、劳酬、学费补偿、代偿、退役士兵、信息登记和岗位招聘均为强正向词。
- 名单公示和到账通知保留在待复核层；工作动态中的活动回顾才应降权。

### 校团委 / 未来网

- 机会类内容集中在补招、竞赛、课题申报、培训班、志愿服务、社会实践和学生社团。
- “通知公告”和“制度文件”都可能有用，也都可能包含结果稿，不能只按栏目过滤。
- 拟录取、拟任、补招人选、推优入党等可能要求确认，进入待复核；纯获奖名单和表彰结果降权。

### 第二课堂

- 采集接口已经只留下报名未截止或活动未结束的记录，因此站点本身是强正向先验。
- 讲座、竞赛、志愿、实践、招新、训练营、工作坊、排练、展演和分享会均可直接视作活动机会。
- “一年级计划”“新生教育”“年级大会”等受众较窄，未做个人年级画像前进入待复核更稳妥。

### 国际交流部

- 当前入口全部是出国（境）学习项目，11 条样本全部被保留。
- 选派、校际交流、交换、公派、访学、寒暑假项目和奖学金是强正向词。
- 仅限硕博或教师的项目排除；拟录取、提名和入选名单进入待复核。

### 综合事务服务中心

- 更新少，主要发布寒暑假开放、办事时间、作息和服务调整。
- 这类标题不是竞赛机会，但属于学生需要关注的校园运行事务，应保留或复核。

### 信息公开网

- 内容以预算、决算、审计、采购和学校治理为主，整体先验较低。
- 仅当标题直接涉及学生、奖助学金、收费、学费、住宿费、招生、就业、培养方案等事项时提高优先级。

### 科学技术发展研究院

- 当前 9 条样本多为国家自然科学基金、重点研发计划、科技奖励、知识产权和计划书等教师/科研管理事项。
- 本站的“申报”“遴选”“项目”不能沿用全站正向含义；只有同时出现本科生、大学生、青年学生、学生招募、科普、开放日、讲坛或讲座时才提高优先级。

## 使用方式

```powershell
python scripts/analyze_site_keywords.py --output data/runs/site_keyword_analysis.md
```
