# 一键测试今日推送

在项目根目录双击 `test_today_push.cmd`。

程序会依次完成：

1. 检查 GitHub 登录状态；
2. 触发 `daily-notice-digest.yml` 云端任务；
3. 等待采集、附件解析、DeepSeek 分析和飞书推送；
4. 成功时提示查看飞书，失败时直接显示错误日志。

DeepSeek API Key 和飞书 Webhook 都保存在 GitHub Secrets 中，本程序不会下载、读取或显示它们。

## 第一次使用

电脑需要安装 [GitHub CLI](https://cli.github.com/)。如果尚未登录，程序会引导打开浏览器登录 GitHub。

## 关于重复测试

系统保留历史记录并去重。同一批信息已经成功推送后，再运行测试通常不会重复轰炸飞书；当天没有新增有效信息时，也可能不发送消息。这表示去重逻辑正常工作。
