# 一键测试今日推送

在项目根目录双击 `test_today_push.cmd`。

程序会依次完成：

1. 检查 GitHub 登录状态；
2. 触发 `daily-notice-digest.yml` 云端任务；
3. 等待采集、附件解析、DeepSeek 分析和飞书推送；
4. 成功时提示查看飞书，失败时直接显示错误日志。

DeepSeek API Key 和飞书 Webhook 都保存在 GitHub Secrets 中，本程序不会下载、读取或显示它们。

## 第一次使用

电脑需要安装 [GitHub CLI](https://cli.github.com/)。如果尚未登录，程序会自动选择 HTTPS，并引导打开浏览器完成一次 GitHub 授权；以后不再重复登录。

## 关于重复测试

一键测试使用强制发送模式，会绕过日报消息的历史去重，因此每次测试都应在飞书收到一条消息；正式的每日 22:00 任务仍然去重，不会重复轰炸。
