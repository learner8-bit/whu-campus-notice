# 附件与外部链接解析

系统只对当天新发现的通知进行有界解析，不会把附件二进制文件提交到仓库或发送到飞书。

## 当前能力

- PDF：使用 `pypdf` 提取文字；扫描图片型 PDF 暂不做 OCR，会保留下载链接并标记为空或扫描件。
- Word：读取现代 `.docx`；旧版 `.doc` 暂时只提供下载链接。
- Excel：读取 `.xlsx` / `.xlsm` 的单元格文字；旧版 `.xls` 暂时只提供下载链接。
- 文本：支持 `.csv` 和 `.txt`。
- 外部链接：继续读取通知正文中的公开 HTTP/HTTPS 外链，包括校外报名页和竞赛官网；拒绝 localhost、私网地址、非标准端口和非 HTTP 协议。
- 内容提取：从附件和外部页面中优先摘取报名、申请、截止、对象、条件、材料、费用、名额、时间、地点和联系方式等句子，并补充到通知正文和摘要后再筛选。

## 流量与安全限制

- 每个附件最多 8 MB。
- 每个外部页面最多 1.5 MB。
- 每条通知最多解析 4 个附件、跟进 3 个外链。
- 每个站点每轮解析总下载量最多 32 MB。
- 下载内容只保存在内存中，解析后立即释放；SQLite 只保存提取出的文字、解析状态和原始 URL。
- 压缩包、可执行文件、旧版 Office 文件和未知格式不自动展开。

## 手机查看

飞书日报为每条通知显示原文、附件下载链接和外部报名/官网链接。点击附件链接后，由飞书内置浏览器或手机系统浏览器决定是在线预览还是弹出下载选项。机器人无法强制手机弹出系统下载框，但不会把大量附件主动推送到手机。
