# 信息源清单

每日任务目前扫描以下 10 个站点组，全部统一转换为 `Notice`，共用筛选、SQLite 去重和飞书日报流程。

| site_id | 信息源 | 当前入口与范围 | 详情能力 |
|---|---|---|---|
| `eis` | 电子信息学院 | 综合、本科生教育、学工、科研、讲座、留学等 8 个栏目 | 正文、附件、正文链接 |
| `undergraduate_school` | 本科生院 | 学生通知、综合业务 | 正文、附件；部分旧页面受验证码限制 |
| `whu_main` | 武汉大学官网 | 通知公告 | 正文、附件；同时兜底学工部等职能部门公开通知 |
| `student_aid` | 学生资助管理中心 | 通知公告、勤助信息 | 正文、附件、正文链接 |
| `youth_league` | 校团委 / 未来网 | 通知公告、制度文件首页最新内容 | 标题、日期、原文链接；详情页当前受验证码限制 |
| `second_classroom` | 第二课堂综合服务平台 | 公开课程活动接口 | 类别、简介、报名时间、活动时间、地点、名额、学时 |
| `international_office` | 国际交流部 | 国家公派及亚洲、欧洲、美洲大洋洲、非洲、港澳台、短期项目 | 正文、附件、正文链接 |
| `service_center` | 综合事务服务中心 | 通知公告 | 正文、附件、正文链接 |
| `information_disclosure` | 信息公开网 | 最新公开中的本站内容 | 正文、附件；外链内容由对应原站采集，避免重复 |
| `science_technology` | 科学技术发展研究院 | 通知公告 | 大部分正文和附件；少量页面受验证码限制 |

党委学生工作部官网目前要求通过武汉大学 VPN 访问，GitHub Actions 无法使用个人校园登录。因此暂不伪装成“直连成功”，公开内容由武汉大学官网通知公告和学生资助管理中心两个入口兜底。后续若学工部恢复公开列表或提供公开接口，可直接增加独立适配器。

所有网站配置集中在 `config/campus_sources.json`。Visual SiteBuilder 类网站复用 `generic_vsb.py`；第二课堂因使用公开 JSON 接口，使用独立适配器。`rules_v1` 未因新增网站而修改。
